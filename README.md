# vkbot: статистика по обсуждениям сообществ VK

Приложение с веб-интерфейсом, которое работает на вашем компьютере. Оно собирает сообщения из обсуждений одного или нескольких сообществ, у каждого сообщества свой период, и считает по каждому автору:

| Колонка | Как считается |
|---|---|
| Сообщений | количество сообщений за выбранные сутки |
| Из них бонусных | сообщения, которые начинаются со строки «Бонусные баллы: …» |
| Символов | символы учтённого текста (строка «Бонусные баллы» не считается) |
| Символов с ×2 | обычные сообщения ×1 + текст после строки «Бонусные баллы» ×2 |
| **Бонусные баллы** | «Символов с ×2» / делитель (по умолчанию 500), округление до 2 знаков |

Сообщения, у которых **первая строка — «не считать»** (отдельной строкой, регистр не важен), в статистику не входят: ни в число сообщений, ни в символы, ни в активность обсуждений. Сколько таких сообщений пропущено, видно над таблицей.

Результаты показываются по каждому сообществу отдельно и в сводной таблице, где один человек суммируется по всем сообществам.

## Быстрый старт (Windows)

1. Установите **Java 11 или новее**: `winget install EclipseAdoptium.Temurin.21.JRE` или установщик с adoptium.net с галочкой «Add to PATH».
2. Дважды щёлкните `run-demo.bat`, чтобы посмотреть интерфейс на сгенерированных данных.
3. Дважды щёлкните `run.bat`. Откроется окно консоли (в нём журнал и ошибки, **не закрывайте его**) и страница `http://localhost:8765` в браузере. `config.properties` для этого **не нужен**.
4. **Ключ доступа VK** (блок вверху страницы):
   1. Введите **ID приложения VK** (client_id), например `1234567`, и нажмите «Запомнить». Это делается один раз.
   2. Нажмите **«Получить ключ в VK»**. Откроется VK: войдите под администратором и нажмите «Разрешить». Дальше ключ возвращается в программу одним из двух способов:
      * **Автоматически.** Добавьте `http://localhost:8765/callback` в «Доверенный redirect URL» в настройках приложения VK. Тогда VK сам вернёт ключ в программу. Если VK покажет ошибку `redirect_uri`, значит для вашего типа приложения так нельзя, и нужен второй способ.
      * **Через закладку.** Один раз перетащите кнопку «→ vkbot» со страницы программы на панель закладок браузера. После «Разрешить» VK откроет страницу `blank.html`; нажмите на ней закладку «→ vkbot», и ключ сам уйдёт в программу.
   3. Запасной вариант: вставить ключ или адрес `blank.html#access_token=…` в поле вручную.

   Программа сразу проверяет ключ в VK и показывает имя владельца. Ключ должен быть получен на этом же компьютере и в той же сети. На диск ключ не пишется, а ID приложения и выбранный способ запоминаются.
5. **Сообщества**: добавьте по адресу и выберите период в календаре (сутки включительно). Есть кнопка «один период для всех». Выбор двухуровневый:
   * галочка **«Считать»** у сообщества решает, участвует ли оно в следующем подсчёте;
   * кнопка **«Обсуждения: N из M ▾»** раскрывает список обсуждений сообщества с такими же галочками. Есть кнопки «Отметить все», «Снять все» и «Обновить список из VK». Новые обсуждения, появившиеся в VK, по умолчанию считаются.
6. Укажите **делитель** и нажмите **Посчитать**. Строку автора можно раскрыть, чтобы увидеть его сообщения (бонусные помечены ×2). Таблица выгружается в CSV для Excel.

`config.properties` нужен только для дополнительных настроек: порт, часовой пояс, маркер бонусной строки, постоянный ключ (`vk.access_token`), кнопка «Получить ключ в VK» (`vkapp.client_id`). Образец лежит в `config.example.properties`.

**Что сохраняется между запусками** (файл `communities.json` рядом с `run.bat`): список сообществ, галочки «Считать» у сообществ, список обсуждений с их галочками и делитель.
**Что не сохраняется:** ключ VK (вводится заново при каждом запуске) и периоды дат (при запуске у всех сообществ стоят последние 7 дней без сегодняшнего, а изменения действуют до закрытия программы).

## Что потребуется от администратора сообщества

| Сообщество | Способ (`vk.auth`) | Что нужно |
|---|---|---|
| **Закрытое / частное** | `vkapp` | Мини-приложение на dev.vk.com (только ради его ID). Ключ берётся при запуске через браузер |
| Закрытое / частное | `vkid` | Приложение VK ID (нужен ИНН РФ) и один вход администратора через `login.bat` |
| Открытое | `token` | Сервисный ключ приложения в `vk.access_token` |

Ключ сообщества из раздела «Управление → Работа с API» **не подходит**: методы обсуждений (`board.*`) с ним не работают. 
### Закрытое сообщество: ключ через мини-приложение (`vkapp`)

Бессрочный ключ (`offline`) VK мини-приложениям не выдаёт: будет ошибка `invalid scope`. Ключ без дополнительных прав живёт около суток, поэтому приложение получает его само при запуске:

1. На dev.vk.com создайте мини-приложение (публиковать и привязывать к сообществу не нужно) и скопируйте его **ID**.
2. В `config.properties`:
   ```properties
   vk.auth=vkapp
   vkapp.client_id=ID_мини_приложения
   vk.group_id=адрес_или_id_сообщества
   ```
3. Запустите `run.bat`. Откроется браузер со страницей VK:
   * при первом запуске нажмите «Разрешить» (в браузере должен быть выполнен вход под администратором);
   * браузер перейдёт на `https://oauth.vk.com/blank.html#access_token=...`. Скопируйте адрес целиком, вставьте в консоль и нажмите Enter.
4. Ключ сохранится в `vk-token-cache.properties` и будет использоваться, пока не истечёт. Через сутки `run.bat` снова откроет браузер. Раз доступ уже разрешён, VK сразу покажет адрес с ключом, останется только скопировать и вставить его.

Без вставки: если в настройках мини-приложения можно добавить доверенный адрес `http://localhost:8765/callback`, пропишите `vkapp.redirect_uri=http://localhost:8765/callback`. Тогда ключ забирается автоматически: браузер открылся, страница сказала «Готово», отчёт строится дальше.

Если VK ответит ошибкой 5 (ключ недействителен), сохранённый ключ сбрасывается, и при следующем запуске берётся новый.

### Закрытое сообщество: вход через VK ID (делается один раз)

1. Откройте [id.vk.com/about/business/go](https://id.vk.com/about/business/go) и создайте приложение, платформа **Web**.
2. В настройках приложения:
   * в **«Доверенный Redirect URL»** добавьте `http://localhost:8765/callback`;
   * скопируйте **ID приложения**.
3. В `config.properties` укажите:
   ```properties
   vk.auth=vkid
   vkid.client_id=ID_приложения
   vkid.redirect_uri=http://localhost:8765/callback
   vk.group_id=адрес_или_id_сообщества
   ```
4. Запустите `login.bat`. Откроется браузер, войдите **под администратором сообщества** и нажмите «Разрешить». Приложение само получит ответ на `localhost` и сохранит вход в `vkid-token.properties`.
5. Дальше просто запускайте `run.bat`.

Как это работает: VK ID выдаёт ключ на час и refresh-токен. При каждом запуске `run.bat` меняет refresh-токен на свежий ключ и сразу сохраняет новый refresh-токен. Пока приложение запускается хотя бы раз в несколько месяцев, повторный вход не нужен. Если VK всё-таки сбросит вход (смена пароля, «завершить все сеансы», долгий перерыв), `run.bat` попросит снова запустить `login.bat`.

Если VK не принимает `localhost` как Redirect URL, укажите любой свой адрес, например `https://ваш-сайт/vkbot`, и в настройках приложения, и в `vkid.redirect_uri`. Тогда после входа `login.bat` попросит вставить адрес из строки браузера.

Если при запуске ошибка 15 или 7 (нет доступа), добавьте в настройках приложения VK ID доступ к сообществам и пропишите `vkid.scope=groups`, затем повторите `login.bat`.

> `vkid-token.properties` даёт доступ к аккаунту администратора. Не пересылайте его и не кладите в общие папки. Отозвать доступ можно в настройках VK, в разделе приложений и сайтов.

### Открытое сообщество: сервисный ключ

1. Создайте приложение на [id.vk.com](https://id.vk.com/about/business/go).
2. Скопируйте **«Сервисный ключ доступа»**.
3. В `config.properties` пропишите `vk.auth=token` и `vk.access_token=ключ`.

Также нужно, чтобы в сообществе были включены «Обсуждения» и разделы были видимы тому, от чьего имени идёт доступ.

## Как это работает

| Шаг | Метод VK API | Зачем |
|---|---|---|
| 1 | `groups.getById` | Определить id сообщества по адресу или короткому имени |
| 2 | `board.getTopics` (order=1, по 100) | Список обсуждений. Темы, которые не обновлялись за период, пропускаются |
| 3 | `board.getComments` (sort=desc, extended=1, по 100) | Сообщения от новых к старым. Чтение темы останавливается на первом сообщении старше периода. Имена авторов приходят в том же ответе |

* Запросы идут с паузой около 350 мс (лимит VK около 3 запросов в секунду). При ошибках 6 и 10 и сетевых сбоях запрос повторяется.
* Если одну тему прочитать не удалось, она пропускается и попадает в предупреждение в отчёте. Код выхода в этом случае 2.
* Символы считаются по Unicode (эмодзи = 1). Перед подсчётом разметка ответов `[id123:bp-…|Имя]` заменяется на «Имя».
* Сообщения от имени сообщества (`from_id < 0`) показываются отдельным автором с пометкой «сообщество».
* Учитывается дата создания сообщения. Редактирование и удаление на неё не влияют.

## Расширение статистики

### Без программирования: regex-метрики в config.properties

```properties
metric.hours.type=regex
metric.hours.title=Часы
metric.hours.pattern=Часов:\\s*(\\d+(?:[.,]\\d+)?)
metric.hours.aggregate=sum        # count | sum | avg | min | max | list | distinct
```

Новая колонка появится в сводной таблице и у каждого сообщения.

### В коде: своя метрика

1. Создайте класс, реализующий `vkbot.stats.Metric`:
   ```java
   public final class Questions implements Metric {
       public String key()   { return "questions"; }
       public String title() { return "Вопросов"; }
       public Object postValue(Post p) { return p.getText().contains("?") ? 1 : 0; }
       public Object aggregate(List<Post> posts) {
           return posts.stream().filter(p -> p.getText().contains("?")).count();
       }
   }
   ```
   `Post.getRaw()` содержит полный JSON сообщения от VK (вложения, лайки и т.п.).
2. Зарегистрируйте её в `MetricRegistry.builtIns()`: `m.put("questions", Questions::new);`.
3. Добавьте `questions` в `metrics=` в конфиге.

Если нужны новые поля из VK API, допишите параметры запроса в `VkClient.forEachCommentPage`.

## Сборка

Внешних зависимостей нет, нужен только Maven и JDK 11 или новее.

```bash
mvn package    # собирает папку dist/: vkbot.jar, скрипты .bat, README, config.example.properties
mvn install    # то же + архив target/vkbot-<версия>.zip с папкой vkbot/ для передачи администратору
```

Пользовательские файлы в `dist/` (`config.properties`, `communities.json`, `logs/`, `reports/`) сборка не трогает, и в архив они не попадают: туда входит только `vkbot.jar`, `*.bat`, `README.md` и `config.example.properties`.

Структура:

```
src/main/java/vkbot/
  App.java                 точка входа, период, обработка ошибок
  config/                  чтение config.properties
  web/                     локальный сервер, API для страницы, хранение сообществ
  resources/web/index.html страница интерфейса
  auth/                    вход через VK ID / ключ приложения (PKCE, автообновление ключа)
  vk/                      VK API: транспорт, повторы, лимиты; DemoVkTransport для --demo
  collect/                 сбор сообщений по темам, нормализация текста
  stats/                   Metric (точка расширения), реестр, группировка по авторам
  stats/metrics/           встроенные и regex-метрики
  report/                  HTML-отчёт
  json/                    минимальный JSON-парсер
src/dist/                  скрипты запуска (run.bat, run-demo.bat, login.bat)
dist/                      собранный дистрибутив (создаётся сборкой, в git не хранится)
```

Запуск вручную: `java -jar vkbot.jar [config.properties] [--demo]` для интерфейса, `--cli` для одного HTML-отчёта по `vk.group_id` без интерфейса, `--login` для входа через VK ID. Любой параметр можно переопределить через `-Dключ=значение`, например `-Dperiod.days=14`.
