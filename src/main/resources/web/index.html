Подсчёт

Укажите делитель и запустите расчёт по отмеченным сообществам.

Бонусные баллы = (символы обычных сообщений + 2 × символы текста после строки «Бонусные баллы: …») / делитель. Сама строка «Бонусные баллы» не считается. Сообщения берутся за выбранные сутки каждого сообщества. Символы считаются без пробелов, переносов строк и невидимых символов. Сообщения с первой строкой «не считать» входят в число сообщений и активность, но не дают символов и баллов.
